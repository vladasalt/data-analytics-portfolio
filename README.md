# Vlada Saltykova — Data Analytics & Coding Portfolio

A curated portfolio of quantitative, business analytics and front-end coding projects demonstrating data cleaning, statistical testing, regression, visualisation, programming and analytical communication using **R, Python, HTML, CSS and JavaScript**.

## 📊 Data Analytics Projects

### 01 — NHS Satisfaction Analysis
British Social Attitudes Survey 2021 | 3,307 respondents

Analysis of NHS satisfaction using descriptive statistics, hypothesis testing and linear regression.

**Methods:** t-test, Chi-square test, linear regression, model diagnostics  
**Tools:** R

[View project files](01_nhs_satisfaction/)

### 02 — Customer Churn & Retention Analysis
IBM Telco Customer Churn | 7,043 customer records

Analysis of churn patterns by contract type, payment method, tenure and monthly charges, supported by statistical testing and business interpretation.

**Methods:** descriptive analysis, Chi-square tests, segmentation  
**Tools:** R / Python

[View project files](02_customer_churn/)

### 03 — Restaurant Spending Analysis
Restaurant bills dataset | 244 observations

Quantitative analysis of restaurant spending, examining differences by smoking status and day and the relationship between party size and total bill.

**Methods:** Welch t-test, Chi-square test, linear regression, residual diagnostics, robust standard errors  
**Tools:** Python, Pandas, SciPy, Statsmodels

[View project files](03_restaurant_spending/)
