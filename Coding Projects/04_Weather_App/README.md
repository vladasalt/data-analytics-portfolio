# 🌤 Weather App

A lightweight front-end project built with **HTML, CSS and JavaScript**.

## Features

- Weather interface with current conditions
- Minimum and maximum temperatures
- Three-day forecast section
- Interactive **Change city** button
- JavaScript DOM manipulation
- Conditional weather emoji based on temperature
- Hover interactions and simple responsive viewport setup

## Technologies

- HTML5
- CSS3
- JavaScript

## How it works

The application starts with example weather information. When the user clicks **Change city**, JavaScript asks for a city and temperature, evaluates the temperature and updates the main heading dynamically.

## Important note

This version is a front-end practice project rather than a live weather-data application. The forecast values are static and the interaction uses browser prompts.
